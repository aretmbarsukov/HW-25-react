# КАДР — пошук фільмів

Односторінковий React-застосунок для перегляду популярних фільмів і пошуку за
назвою. Дані про фільми, акторський склад та відгуки надходять із
[The Movie Database (TMDB)](https://www.themoviedb.org/).

## Запуск локально

1. Встанови Node.js LTS.
2. Створи API-ключ у своєму акаунті TMDB: **Settings → API**.
3. У корені проєкту створи файл `.env` і додай свій ключ:

   ```env
   REACT_APP_TMDB_API_KEY=твій_api_ключ
   ```

   Файл `.env` ігнорується Git. Ключ, використаний у клієнтському
   React-застосунку, доступний у браузері після збірки; обмеж його для свого
   домену в налаштуваннях TMDB і не використовуй тут приватний токен.

4. Встанови залежності та запусти застосунок:

   ```bash
   npm install
   npm start
   ```

   Відкрий [http://localhost:3000](http://localhost:3000). Після створення або
   зміни `.env` перезапусти сервер розробки.

## Маршрути

- `/` — популярні фільми дня.
- `/movies` — пошук фільмів за назвою; пошуковий запит зберігається в URL.
- `/movies/:movieId` — інформація про фільм.
- `/movies/:movieId/cast` — акторський склад у сторінці фільму.
- `/movies/:movieId/reviews` — відгуки у сторінці фільму.

Сторінки завантажуються асинхронно через `React.lazy` і `Suspense`. Невідомі
маршрути перенаправляються на головну.

## Перевірка і збірка

```bash
npm run lint:js
npm run build
```

## GitHub Pages

У `package.json` поле `homepage` налаштоване на
`https://aretmbarsukov.github.io/HW-25-react/`. `BrowserRouter` використовує
`PUBLIC_URL` як `basename`, щоб маршрути працювали під шляхом репозиторію.
Наявний workflow збирає та деплоїть застосунок після пушу в `main`; у
налаштуваннях GitHub Actions для репозиторію потрібні дозволи на запис.

Щоб запити TMDB працювали на опублікованій сторінці, додай API-ключ у
налаштуваннях репозиторію як Actions secret з ім'ям
`REACT_APP_TMDB_API_KEY`. Workflow передасть його у production-збірку. Ключ буде
доступний у коді браузера, тому обмеж його доменом у кабінеті TMDB.
